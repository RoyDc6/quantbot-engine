# 香港市场每日优选个股策略 v1.0

- 版本日期：2026-07-30
- 状态：`PRELIMINARY / RESEARCH_ONLY`
- 范围：恒生综合指数成分股，日频，持有 3–10 个交易日
- 边界：只生成研究候选和回测证据，不连接账户、不生成订单

## 一、结论先行

本策略每天收盘后从当日有效的 HSCI 股票成分中选出 0–5 只 A 类研究候选：

- 市场环境为 `ON` 时最多 5 只；
- `CAUTION` 时最多 3 只；
- `OFF` 或数据状态 `UNKNOWN` 时为空名单；
- 信号使用 T 日已完成日线，最早按 T+1 开盘价模拟成交；
- 最短持有 3 个交易日，最长持有 10 个交易日；
- 默认只纳入 `STOCK`，不把 ETF/REIT 自动混入股票横截面；
- 排名是尽调优先级，不是买入建议，也不直接给出个性化仓位比例。

策略核心是“可投资性过滤 → 市场门控 → 行业中性价量/风险排名 → 候选漏斗”。
它允许没有候选，避免为了凑数而强制持仓。

当前实现已通过合成数据端到端测试、未来数据污染测试和 Futu 只读烟测，但尚未
用完整的点时 HSCI 历史成分、公司行动和停牌档案得到真实样本外结论。因此，
任何真实收益或 alpha 表述都应暂缓。

## 二、目标与非目标

### 2.1 目标

1. 每日稳定地产生一份可解释、可复核的香港股票研究优先级。
2. 捕捉 3–10 个交易日尺度的趋势延续、相对强度和成交确认。
3. 在弱市、流动性不足、异常跳空或高波动时主动降级或空仓。
4. 用严格的点时数据和 T+1 成交规则避免幸存者偏差与未来函数。
5. 为后续基本面、公告、估值和催化剂核查提供精简候选池。

### 2.2 非目标

- 不预测盘中最低点或最高点；
- 不做日内、高频、融券或做空；
- 不把当前成分股名单回填为历史股票池；
- 不把后来发布的财报、行业分类或公司行动用于更早日期；
- 不调用 QuantBot 的 XMM、VP、FusionController、Gate 或执行模块；
- 不读取账户、持仓、购买力，也不提交订单。

## 三、股票池与点时规则

### 3.1 基准股票池

HSCI 作为广泛香港股票市场母池。官方方法把符合资格证券按累计市值覆盖划分，
综合指数目标覆盖约 95% 的累计市值，并按既定检讨和快速纳入规则调整成分。
正式定义以[恒生指数公司 HSCI 方法论](https://www.hsi.com.hk/static/uploads/contents/en/dl_centre/methodologies/IM_sizeindexese.pdf)
为准。

本机 Futu OpenD 在 2026-07-31 对 `HK.800701` 的只读观察为 531 个 `STOCK`
当前成分。这个数字是当日快照，不是历史常数。每日研究筛选先保留全部 HSCI
股票成分作为母池，再按 `SESSION_DATE` 同日总市值降序（同值按代码升序）取
Top 50 作为可执行的横截面日筛池。Top 50 是数据工程与研究容量边界，不代表
HSCI 官方指数分层；其排名证据不完整时必须失败关闭，不能回退到任意小样本。

### 3.2 点时成分

历史股票池必须采用事件区间：

```text
symbol + effective_from + effective_to + source_asof
```

在交易日 t，仅允许：

```text
effective_from <= t <= effective_to
```

当前 Futu `get_plate_stock` 接口可提供当前板块成分，详见
[Futu Get Plate Stock](https://openapi.futunn.com/futu-api-doc/en/quote/get-plate-stock.html)；
它不证明历史日期的成分。若当前快照的 `source_asof` 晚于回测日期，严格模式会
失败关闭。只有显式使用 `--allow-survivorship-bias` 才能继续诊断，并强制标记
`SURVIVORSHIP_BIASED`。

### 3.3 同发行人和证券类型

- 默认 `allowed_security_types = ("STOCK",)`；
- 同发行人的不同股类每天最多 1 只；
- 退市、被剔除、停牌和代码变更记录必须保留；
- 行业与发行人映射同样需要点时版本，不能使用今天的分类覆盖过去。

## 四、时间轴和信号冻结

```text
T 日收市
  → 16:30 HKT 后确认日线完成并冻结数据快照和版本
  → 数据质检、市场门控、过滤、排名
  → 输出 A/B/C/Reject Markdown
  → T+1 开盘才允许进入研究成交模拟
```

规则：

- 只使用实际出现于基准日线序列的交易日，不猜测周末或假期；
- 今日 16:30 HKT 前不得启动数据读取或筛选；
- 半日市也统一等到 16:30 后处理，宁可保守延迟；
- 缺任一关键字段、基准不完整或点时成分不覆盖时，不生成确认候选；
- 每次运行记录数据源、截止日期、配置版本和质量警告。

## 五、可投资性过滤

候选必须同时满足：

| 过滤项 | 基线参数 | 理由 |
|---|---:|---|
| 点时 HSCI 成分 | 当日有效 | 防止幸存者偏差 |
| 证券类型 | `STOCK` | 保持横截面一致 |
| 已完成日线 | 必须 | 排除盘中未完成数据 |
| 停牌/量额 | 非停牌且量额 > 0 | 保证可观察成交 |
| 历史长度 | ≥120 日 | 覆盖 60 日因子及缓冲 |
| 股价 | ≥HK$1 | 降低极低价跳动噪声 |
| 60 日成交额中位数 | ≥HK$30m | 流动性底线 |
| 近 20 日有效交易日 | ≥18 | 排除间歇成交 |
| 20 日年化实现波动 | ≤80% | 排除极端波动 |
| 单日绝对收益 | ≤25% | 排除事件跳空/异常值 |
| 趋势 | Close > MA20 > MA60 | 只做正向趋势延续 |

这些门槛是预先设定的研究先验，不是样本内寻优结果。正式验证应对成交额
HK$20m/HK$30m/HK$50m、波动 60%/80% 和趋势过滤做敏感性矩阵，不得只报告
最优组合。

## 六、市场环境门控

基准为 HSCI `800701.HK`。每日计算三项：

1. HSCI Close > MA60；
2. HSCI MA20 > MA60；
3. 可计算成分中 Close > MA20 的比例（市场宽度）≥55%。

门控：

| 状态 | 条件 | A 类上限 |
|---|---|---:|
| `ON` | 三项全部成立 | 5 |
| `CAUTION` | 至少两项成立且宽度 ≥45% | 3 |
| `OFF` | 其余可计算情形 | 0 |
| `UNKNOWN` | 基准或宽度不足 | 0 |

门控只控制是否产生候选和候选数量，不改变单股因子定义，减少在不同市场阶段
反复重新拟合权重的自由度。

## 七、因子与评分

所有特征在 T 日收盘后计算，只引用日期不晚于 T 的记录。各原始因子先转为
0–1 横截面百分位，再按 70% 全市场排名 + 30% 同行业排名混合。行业内少于
3 个有效样本时退回全市场排名。

### 7.1 权重

| 组件 | 权重 | 原始信号 |
|---|---:|---|
| 动量 | 20% | `mom_20_5` 与 `mom_60_5` 均值 |
| 相对强度 | 15% | 个股 20 日收益减 HSCI 20 日收益 |
| 趋势质量 | 15% | 均线趋势强度与 20 日路径效率 |
| 价量确认 | 20% | 5/20 日成交额比与上涨日成交额占比 |
| 风险质量 | 15% | 低实现波动、低回撤 |
| 入场质量 | 15% | 距 MA20 约 0.5 ATR 最优，惩罚追高 |

总分：

```text
Score =
  0.20 × Momentum
  + 0.15 × RelativeStrength
  + 0.15 × TrendQuality
  + 0.20 × Participation
  + 0.15 × RiskQuality
  + 0.15 × EntryQuality
```

### 7.2 主要公式

```text
mom_20_5 = Close[t-5] / Close[t-20] - 1
mom_60_5 = Close[t-5] / Close[t-60] - 1
relative_strength_20 = return_20(stock) - return_20(HSCI)
trend_strength = Close/MA20 - 1 + MA20/MA60 - 1
trend_efficiency_20 = return_20 / Σ(abs(daily_return), 20)
turnover_ratio_5_20 = median(turnover, 5) / median(turnover, 20)
risk_raw = -realized_vol_20 + drawdown_20
extension_atr_20 = (Close - MA20) / ATR20
entry_quality = -abs(extension_atr_20 - 0.5)
```

5 日跳过区间降低短期反转对中期动量的干扰。学术研究为动量和流动性效应提供
研究动机，可参考
[Jegadeesh & Titman (1993)](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.1993.tb04702.x)、
[Fama & French (2012)](https://doi.org/10.1016/j.jfineco.2012.05.011) 和
[Amihud (2002)](https://www.sciencedirect.com/science/article/pii/S1386418101000246)。
这些文献不等于本策略已在香港样本上证明有效。

### 7.3 基本面与催化剂

v1 不把基本面质量塞入机械总分，因为当前没有带公告发布日期的点时财务数据。
候选进入 A 类后必须继续核查：

- 最新公告、业绩、盈利预警和管理层指引；
- 估值相对历史及同业的位置；
- 公司行动、配售、供股、禁售到期；
- 未来 10 个交易日内的业绩或重大事件；
- 行业拥挤、政策和汇率敏感性。

只有获得点时财务数据后，v1.1 才可预先定义质量因子，并从现有权重中腾挪，
不得事后为改善回测而追加。

## 八、排名、候选漏斗和否决

1. 按综合分降序；
2. 同分时按证券代码升序，保证可复现；
3. 每行业最多 2 只；
4. 同发行人最多 1 只；
5. 按市场门控截取 A 类；
6. Rank 不高于 `max(15, 2 × top_k)` 的未入选股票为 B 类观察；
7. 其余合格股票为 C 类屏幕标记；
8. 不合格股票为 Reject，并保留首要和完整排除原因。

硬否决包括：数据不完整、非点时成分、停牌、量额为零、流动性不足、历史不足、
极端波动、事件跳空和趋势不合格。A 类标签只代表后续尽调优先级。

## 九、研究回测规则

### 9.1 进入

- T 日 A 类信号；
- T+1 首个可用开盘价；
- 停牌或无有效开盘价时不成交；
- 只做多；
- 研究账户初值 HK$1m，仅用于跨方案可比，不代表用户仓位建议；
- 单证券研究名义金额不超过 60 日成交额中位数的 1%。

### 9.2 退出

- 持有不足 3 个交易日：除数据不可交易外不因排名波动退出；
- 持有满 3 日后，出现不合格、Rank >15 或市场 `OFF`，在下一开盘退出；
- 持有满 10 日后，在下一可交易开盘强制退出；
- 停牌时退出延迟并继续使用最后有效价格标记；
- 同一证券在强制退出当日不能立即重入，下一次收盘重新评估。

### 9.3 成本

基线单边成本为 24.27 bps：

| 成本 | 单边 bps |
|---|---:|
| 股票印花税 | 10.000 |
| 交易费 | 0.565 |
| SFC 交易征费 | 0.270 |
| AFRC 交易征费 | 0.015 |
| 结算费 | 0.420 |
| 模拟券商佣金 | 3.000 |
| 模拟滑点 | 10.000 |
| 合计 | 24.270 |

法定费率以
[HKEX 证券交易费用](https://www.hkex.com.hk/Services/Rules-and-Forms-and-Fees/Fees/Securities-%28Hong-Kong%29/Trading/Transaction?sc_lang=en)
及[结算费调整公告](https://www.hkex.com.hk/news/market-communications/2025/250221news?sc_lang=en)
为依据。实际券商最低佣金、印花税取整和盘口冲击尚未建模。压力测试把滑点
提高至 25 bps，则单边约 39.27 bps、往返约 78.54 bps。

### 9.4 公司行动

严格历史回测使用原始不复权价格加点时公司行动账本，并默认请求
`AuType.NONE`。每日横截面日筛允许使用在 `SESSION_DATE` 当日 16:30 HKT 后
冻结的 `AuType.QFQ` 序列，以消除近期除权造成的伪动量；同时必须保存同日
Futu rehab 事件证据。QFQ 快照只对该 `SESSION_DATE` 有效，禁止在未来日期
重抓后回写旧日筛。由于现金股息、供股、拆合股和代码变更现金流尚未完整实现，
真实历史回测状态仍须保持 `PRELIMINARY`。

## 十、验证方案

### 10.1 数据质检

- HSCI 交易日连续性；
- `date + symbol` 唯一；
- OHLC 包络、有限值、量额非负；
- 每日点时成分覆盖；
- 停牌、退市、被剔除证券保留；
- 公司行动和代码变更可追溯；
- 当前快照不允许回填历史；
- 任意未来日期价格改变不得影响过去分数。

### 10.2 时间切分

- 禁止随机切分；
- 因子与阈值先固定，再做 rolling walk-forward；
- 每个测试折与任何阈值调整窗口之间至少 purge 10 个交易日；
- 最终保留最近 12 个月为完全未触碰的 holdout；
- 若数据少于 36 个月或不能覆盖不同市场阶段，只能报告探索性结果。

### 10.3 指标

1. 3/5/10 日横截面 Rank IC；
2. A 类平均收益与全体合格股票等权收益之差；
3. T+1 开盘净收益、换手和成本拖累；
4. 最大回撤、波动、正收益日比例；
5. 按年份、市场门控、行业、市值和流动性分组的稳定性；
6. 正常成本与压力成本的差异；
7. 候选覆盖率、空名单比例和被停牌延迟退出次数；
8. P&L 是否被单一证券、行业或单一时期支配。

### 10.4 升级门槛

升级出 `PRELIMINARY` 前至少应满足：

- 点时成分、已完成日线、历史停牌和公司行动覆盖通过；
- 所有未来数据污染和 T+1 成交测试通过；
- 多个 walk-forward 折中 5/10 日 Rank IC 方向稳定；
- 扣除基线成本后，候选相对合格股票池的中位数超额为正；
- 压力成本、流动性和参数敏感性不使结论集中坍塌；
- 真实持仓模拟补齐 board lot、最低佣金、印花税取整和盘口容量。

这些是研究晋级条件，不是收益承诺。未通过时应保留失败结果，而不是继续寻参
直到得到正收益。

## 十一、每日输出

每日 Markdown 至少包含：

- 截止日期、数据源、配置版本和证据状态；
- HSCI 门控状态与市场宽度；
- A 类候选及六项分数；
- B/C/Reject 漏斗；
- 主要排除原因；
- 每只 A 类的首要反证或待核验事项；
- 点时成分、停牌、公司行动和成本警告；
- 独立的 `综述结论`。

如果 A 类为零，应明确输出“允许空名单”，不能把 B 类升级为 A 类凑数。

## 十二、当前证据状态

截至 2026-07-31：

- 策略代码、配置、CLI、Markdown 报告和合成回测可运行；
- 本地单测覆盖点时防护、未来数据不变性、T+1、持有期、成本和模块边界；
- Futu OpenD 当前 HSCI 成分只读调用通过；
- 合成示例没有真实证券，不能用于 alpha 结论；
- 当前成分接口没有历史点时成分，仍不能替代严格历史回测股票池；
- 当日日筛已建立 HSCI Top 50 增量缓存，并要求排名、日线、宽度、行业、停牌、
  公司行动证据达到配置覆盖率；
- 历史公司行动、停牌和行业/发行人点时映射仍需补齐；
- 数据契约达到 `READY` 时可发布当日 0–5 只研究候选；这不等于真实回测通过，
  也不证明存在已验证 alpha。

## 综述结论

推荐版本已经形成一套明确的研究策略：以点时 HSCI 股票成分为母池，用严格
流动性与趋势门槛过滤，以市场环境控制候选数量，再用行业中性的动量、相对
强度、趋势质量、价量确认、风险和入场质量产生每日 0–5 只研究候选；回测采用
T+1 开盘、3–10 日持有、24.27 bps/边成本和 1% 成交额容量约束。

现阶段可以把它用于数据工程、影子筛选和样本外验证，但不能把当前快照或合成
结果解释为已证明的选股收益。下一道真正的门槛是取得完整点时 HSCI 历史成分、
停牌与公司行动数据，并按本文件的 walk-forward 方案验证。
