# QuantBot Engine v0.1.0

`v0.1.0` is the first public community release of QuantBot Engine: a
safety-first quantitative research and paper-trading engine for Hong Kong and
U.S. equities.

## Highlights

- Inspectable research -> decision -> deterministic gate -> simulated execution
  architecture.
- Futu submission remains pinned to `TrdEnv.SIMULATE`; dry-run is the default.
- 55+ offline smoke and safety tests, plus repository credential scanning.
- Structured signals, reports, journals, and reconciliation-oriented provenance.
- Apache-2.0 license and complete contributor and security documentation.
- Optional Codex PR review using trusted triggers, a read-only sandbox, a strict
  JSON schema, and dependency-free output validation.

## Verify the release

```bash
python -m compileall -q unified_runner.py reports/fusion_report_v3.py core
python -m pytest tests/smoke/
python scripts/check_secrets.py
```

These checks are offline and do not require market credentials, a broker
connection, or an OpenAI API key.

## Safety boundary

This release is research and paper-trading software, not investment advice. It
does not support real-money trading, and AI-generated output has no broker or
execution authority.

See [`CHANGELOG.md`](../../CHANGELOG.md) for the full release summary and known
limitations.
