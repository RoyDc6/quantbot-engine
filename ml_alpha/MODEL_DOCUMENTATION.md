## 1. 模型概述

### 1.1 目标
构建港股Alpha选股模型，通过融合**缠论技术分析**与**复杂度理论**两类因子，捕捉市场的结构性机会。

### 1.2 核心假设
- **缠论假设**: 价格走势由分型(顶/底分型)构成，分型之间的平衡关系蕴含趋势信息
- **复杂度假设**: 市场价格的复杂度/规律性可以预测短期方向

### 1.3 数据范围
- **市场**: 港股主板 (约94只主要股票)
- **时间范围**: 2025-09 ~ 2026-04
- **频率**: 日线数据，200日历史

## 3. 因子体系

### 3.1 缠论因子 (Chan Theory Factors)

缠论源自中国操盘手李彪的《缠中说禅》技术分析理论，核心概念包括**分型**、**笔**、**线段**、**中枢**。

#### 3.1.1 分型识别
```
顶分型: 连续三根K线，中间一根最高
底分型: 连续三根K线，中间一根最低
```

#### 3.1.2 因子列表

| 因子名 | 说明 | RankIC | 方向 |
|--------|------|--------|------|
| frac_balance_20 | 20日底分型占比 - 顶分型占比 | **+0.314** | 正向 |
| top_count_20 | 20日顶分型数量 | -0.257 | 反向 |
| fractal_top_5 | 5日顶分型数量 | -0.240 | 反向 |
| fractal_bottom_5 | 5日底分型数量 | +0.198 | 正向 |
| frac_balance_10 | 10日分型平衡度 | +0.187 | 正向 |
| bottom_count_10 | 10日底分型数量 | +0.165 | 正向 |
| top_count_10 | 10日顶分型数量 | -0.156 | 反向 |
| bull_divergence | 底背离信号 | +0.142 | 正向 |
| resonance | 多周期共振 | +0.138 | 正向 |
| td9_count | TD9计数 | +0.098 | 正向 |

#### 3.1.3 核心逻辑
- **底分型多 + 顶分型少** → 看涨信号
- **底分型少 + 顶分型多** → 看跌信号
- **分型平衡度** 衡量多空力量对比

### 3.2 复杂度因子 (Complexity Factors)

复杂度理论源自混沌理论和信息论，通过量化时间序列的复杂度来预测走势。

#### 3.2.1 因子列表

| 因子名 | 说明 | RankIC | 方向 |
|--------|------|--------|------|
| apen_60 | 近似熵 (60日) | **-0.085** | 反向 |
| hurst_60 | Hurst指数 (60日) | **+0.059** | 正向 |
| apen_20 | 近似熵 (20日) | -0.058 | 反向 |
| entropy_60 | 香农熵 (60日) | +0.043 | 正向 |
| higuchi_fd_60 | Higuchi分形维数 (60日) | -0.037 | 反向 |

#### 3.2.2 核心逻辑

**Hurst指数 (H)**
- H > 0.5: 趋势持续性（高H=强趋势）
- H < 0.5: 均值回归
- H ≈ 0.5: 随机游走

**近似熵 (ApEn)**
- 低ApEn: 规律性强，可能持续当前趋势
- 高ApEn: 随机性强，趋势可能反转

**香农熵 (Entropy)**
- 高熵: 价格分布均匀，可能突破
- 低熵: 价格集中，可能盘整

**分形维数 (FD)**
- 高FD: 复杂/混沌
- 低FD: 简单/趋势

#### 3.2.3 窗口选择
```
60日窗口全面优于20日窗口:
- apen_60 RankIC = -0.085 vs apen_20 = -0.058
- entropy_60 RankIC = +0.043 (无20日数据)
- hurst_60 RankIC = +0.059 vs hurst_20 (未计算)
```

## 4. 模型架构

### 4.1 融合策略

采用**IC加权融合**，根据因子历史IC值分配权重：

```
融合得分 = Σ (因子权重 × 标准化因子值)

其中权重 = IC值 / Σ|IC值|
```

### 4.3 分层组合

根据融合得分将股票分为5档：
- **Q5 (Top 20%)**: 最高得分，买入信号
- **Q4**: 较高得分
- **Q3**: 中性
- **Q2**: 较低得分
- **Q1 (Bottom 20%)**: 最低得分，回避信号

   - 缠论单独: RankIC=0.378
   - 融合后: RankIC=0.384 (+1.6%)
   - 说明两类因子有一定重叠

## 6. 使用方法

### 6.1 日常使用

1. **自动信号**: 工作日上午10:00自动生成
2. **手动触发**: 运行 `generate_signals.py`
3. **查看信号**: 读取 `signals/signal_YYYYMMDD.csv`

### 6.2 信号解读

| 信号类型 | 得分范围 | 操作建议 |
|----------|----------|----------|
| 强烈买入 | > +0.25 | 重点关注，可建仓 |
| 买入 | +0.10 ~ +0.25 | 适度关注，观察 |
| 中性 | -0.10 ~ +0.10 | 观望 |
| 卖出 | -0.25 ~ -0.10 | 减仓 |
| 强烈卖出 | < -0.25 | 清仓回避 |

### 6.3 仓位管理

- 单票建议仓位: 5-10%
- 总仓位建议: 30-50%
- 留有现金: 50-70%

## 7. 风险提示

### 7.1 模型风险

1. **回测偏差**: 历史表现不代表未来
2. **过拟合风险**: 因子权重基于有限历史数据
3. **市场变化**: 市场结构变化可能导致因子失效

### 7.2 操作风险

1. **数据延迟**: TickFlow免费版为日末数据
2. **覆盖有限**: 仅94只港股
3. **交易成本**: 未考虑手续费、滑点

### 7.3 风险控制建议

1. **分散投资**: 不超过20只股票
2. **止损纪律**: 单票亏损>10%止损
3. **定期复盘**: 每月评估模型表现
4. **动态调整**: 根据市场状态调整仓位
