## 一、问题定位：融合框架 0 交易的根因

### 根因 1：融合打分公式符号错误
- **原公式**: `0.202 * (50 - wrsi) + (-0.152) * resonance`
- **结果**: IC=-0.2045（**负的**！）→ 持续做空暴涨股票 → -72.80%收益
- **weekly_rsi IC=+0.2156（动量）**：高RSI→高收益，但原公式给低RSI高分 → 方向反了
- **修复**: `0.202 * (wrsi - 50) + (-0.152) * resonance`

### 根因 2：共振方向意外（+0.0206 而非 -0.023）
- resonance IC=+0.0206（全部数据），但回测最近数据显示 IC=-0.0230
- 融合打分对 resonance 不敏感（0.152×0.02 = 0.003），方向影响小

### 根因 3：TickFlow GBK 编码
- `TickFlow.free()` 打印 emoji 时 Windows GBK 失败
- **修复**: 改用 `TickFlow()`（API Key 版本）

## 四、策略核心逻辑

### 融合打分（港股动量版）
```python
score = 0.202 * (wrsi - 50) + (-0.152) * resonance
# wrsi动量: 高RSI=动量强=BUY信号
# resonance: 高共振=没alpha=扣分
```

### 双系统信号矩阵（趋势自适应）
- **上升趋势**（MA20>MA60）：TA BUY + FM SELL → HOLD（避免踏空）
- **下降趋势**（MA20<MA60）：TA SELL + FM BUY → HOLD（避免接刀）

### 港股 vs 美股 vs A股 公式差异
| 市场 | weekly_rsi | resonance |
|------|-----------|-----------|
| **港股** | **(wrsi-50) 动量** | **-resonance** |
| 美股 SPX | (50-wrsi) 均值回归 | -resonance |
| CSI300 | (50-wrsi) 均值回归 | -resonance |
