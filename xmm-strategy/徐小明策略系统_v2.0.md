# 徐小明交易策略 · 结构量化系统 v2.0

> 本文档基于「趋势为王，结构修边，序列为辅」核心理念，结合同花顺指标公式量化实现。

---

## 一、核心理念

```
趋势为王    → 第一优先级，判断方向
结构修边    → 第二优先级，确认时机
序列为辅    → 第三优先级，精选点位
```

**核心原则**：
- 只做顺势交易，不逆势抄底摸顶
- **趋势变化过程就是分批建仓/建空仓的过程**
- 结构是交易的核心信号，钝化是预警信号
- 钝化必须与序列共振才能生效，结构独立生效

---

## 二、趋势判断（第一优先级）

### 2.1 趋势定义

| 趋势 | 判断条件 | 交易方向 |
|------|----------|----------|
| **多头趋势** | 价格 > MA20 > MA60，且 MA20 向上 | 只做买入，不做空 |
| **空头趋势** | 价格 < MA20 < MA60，且 MA20 向下 | 只做卖出，不做多 |
| **震荡市** | 不满足上述条件 | 观望，不交易 |

### 2.2 分批建仓规则

**趋势变化过程就是分批建仓的过程**：

```
【多头趋势形成过程】
价格上穿MA20（短期反转） → BUY 10%
价格上穿MA60（中期反转） → BUY +10%
趋势确认（MA20>MA60）    → BUY +20%（满仓）
回调底部结构             → BUY 20%（回调买点）
顶部钝化+TD(6-9)        → SELL 30%（趋势终结）

【空头趋势形成过程】
价格下破MA20（短期反转向下） → SELL 10%
价格下破MA60（中期反转向下） → SELL +10%
趋势确认（MA20<MA60）        → SELL +20%（满空）
反弹顶部结构                → SELL 20%（反弹卖点）
底部钝化+TD(6-9)           → BUY 30%（趋势终结）
```

## 三、结构与钝化（第二优先级）

### 3.1 生命周期

```
钝化形成 → 钝化持续 → 结构形成（确认）
                         ↓
              结构持续 → 结构消失（失效）
                         ↓
              钝化消失（DIF继续同向，预警失效）
```

**核心概念**：
- **钝化**：价格创新高/新低，但DIF未创新高/新低 → 预警，动能衰竭信号
- **结构**：钝化后，DIF开始反向运动 → 真正确认信号，可以交易
- **消失**：DIF继续同向运动 → 原信号失效

### 3.2 MACD辅助变量

```python
N1 = 上一次MACD从正转负后经过的bar数（当前在负区间）
M1 = 上一次MACD从负转正后经过的bar数（当前在正区间）

CL1/CL2/CL3 = 本次/前1/前2个正区间的最低收盘价
CH1/CH2/CH3 = 本次/前1/前2个负区间的最高收盘价
DIFL1/2/3   = 对应区间的最低DIF
DIFH1/2/3   = 对应区间的最高DIF
```

### 3.3 底部结构 · 量化条件

**直接底钝化**：
```
CL1 < CL2 AND DIFL1 > DIFL2 AND MACD(-1)<0 AND DIFF<0
```

**隔峰底钝化**：
```
CL1 < CL3 AND DIFL1 < DIFL2 AND DIFL1 > DIFL3 AND MACD(-1)<0 AND DIFF<0
```

**底部结构形成（确认信号）**：
```
REF(底部钝化, 1) AND |REF(DIFF, 1)| >= |DIFF| * 1.01
含义：底部钝化形成后，DIF开始放大（绝对值增大1%以上）
```

### 3.4 顶部结构 · 量化条件

**直接顶钝化**：
```
CH1 > CH2 AND DIFH1 < DIFH2 AND MACD(-1)>0 AND DIFF>0
```

**隔峰顶钝化**：
```
CH1 > CH3 AND DIFH1 > DIFH2 AND DIFH1 < DIFH3 AND MACD(-1)>0 AND DIFF>0
```

**顶部结构形成（确认信号）**：
```
REF(顶部钝化, 1) AND REF(DIFF, 1) >= DIFF * 1.01
```

## 四、TD序列（第三优先级）

| 序列 | 条件 | 含义 |
|------|------|------|
| TD买入序列 | 连续9根K线收盘价 < 4根前收盘价 | 下跌衰竭 |
| TD卖出序列 | 连续9根K线收盘价 > 4根前收盘价 | 上涨衰竭 |

**序列生效条件**：
- 底部钝化（空头趋势）+ TD序列低（6, 7, 8, 9） → 买入生效
- 顶部钝化（多头趋势）+ TD序列高（6, 7, 8, 9） → 卖出生效
- **结构独立生效，无需序列**

## 六、决策流程

```
第一步：判断趋势（趋势为王）
    │
    ├─ 多头趋势 → 分批建多仓
    ├─ 空头趋势 → 分批建空仓
    └─ 震荡市   → 观望
            │
            ↓
第二步：趋势交叉检测
    │
    ├─ 上穿MA20 → BUY 10%
    ├─ 上穿MA60 → BUY 10%
    ├─ 下破MA20 → SELL 10%
    └─ 下破MA60 → SELL 10%
            │
            ↓
第三步：结构检测（优先级高于交叉信号）
    │
    ├─ 底部钝化+TD(6-9) → BUY 30%（最强买入）
    ├─ 底部结构         → BUY 20%
    ├─ 顶部钝化+TD(6-9) → SELL 30%（最强卖出）
    └─ 顶部结构         → SELL 20%
            │
            ↓
第四步：执行交易
```

## 八、止损与止盈

**止损**：
- ATR止损：入场价 ± 3 × ATR(14)
- 固定止损：入场价 ± 5%

**止盈**：
- RSI(14) > 70（多头持仓）→ 部分止盈
- RSI(14) < 30（空头持仓）→ 部分止盈
- 顶部/底部结构形成 → 全部止盈
- 峰值回撤 6% → 跟踪止盈

---

## 九、注意事项

1. **趋势交叉 ≠ 立即满仓**：分批建仓，10% → 10% → 20%
2. **钝化 ≠ 信号**：钝化只是预警，需序列共振才生效
3. **消失 ≠ 错误**：消失表示原信号失效，不做错
4. **均线修复需时间**：反弹初期均线未修复，不急于做多
5. **结构 > 钝化**：结构无需序列即可交易
