# 徐小明交易策略 · 结构量化系统 v1.0

> 本文档基于「趋势为王，结构修边，序列为辅」核心理论，结合同花顺指标公式量化实现。

---

## 一、核心理念

```
趋势为王    → 第一优先级，判断方向
结构修边    → 第二优先级，确认时机
序列为辅    → 第三优先级，精选点位
```

**核心原则**：
- 只做顺势交易，不逆势抄底摸顶
- 结构是交易的核心信号，钝化是预警信号
- 序列仅在钝化出现时才生效

---

## 二、趋势判断（第一优先级）

### 2.1 趋势定义

| 趋势 | 判断条件 | 交易方向 |
|------|----------|----------|
| **多头趋势** | 价格 > MA20 > MA60，且 MA20 > MA60 | 只做买入，不做空 |
| **空头趋势** | 价格 < MA20 < MA60，且 MA20 < MA60 | 只做卖出，不做多 |
| **震荡市** | 不满足上述条件 | 观望，不交易 |

### 2.2 趋势状态机

```
多头趋势 → 震荡市 → 空头趋势
    ↑__________________________|
```

## 三、结构与钝化（第二优先级）

### 3.1 生命周期

```
钝化形成 → 钝化持续 → 结构形成（确认）
                         ↓
              结构持续 → 结构消失（失效）
                         ↓
              钝化消失（DIF继续同向，预警失效）
```

**核心概念**：
- **钝化**：价格创新高/新低，但DIF未创新高/新低 → 预警，动能衰竭信号
- **结构**：钝化形成后，DIF开始反向运动 → 真正确认信号，可以交易
- **消失**：DIF继续同向运动 → 原信号失效，忽略

### 3.2 MACD辅助变量

```python
N1 = 上一次MACD从正转负后经过的bar数（当前处于负区间）
M1 = 上一次MACD从负转正后经过的bar数（当前处于正区间）

CL1 = 本次负区间最低收盘价
CL2 = 前一次正区间最低收盘价
CL3 = 前前一次正区间最低收盘价

CH1 = 本次正区间最高收盘价
CH2 = 前一次负区间最高收盘价
CH3 = 前前一次负区间最高收盘价

DIFL1 = 本次负区间最低DIF
DIFL2 = 前一次正区间最低DIF
DIFL3 = 前前一次正区间最低DIF

DIFH1 = 本次正区间最高DIF
DIFH2 = 前一次负区间最高DIF
DIFH3 = 前前一次负区间最高DIF
```

### 3.3 底部结构 · 量化条件

#### 底部钝化（预警）

**直接底钝化**：
```
CL1 < CL2                    # 价格新低（跌破前正区间低点）
AND DIFL1 > DIFL2            # DIF未新低（DIF高于前正区间最低）
AND REF(MACD, 1) < 0         # 前一根MACD在0轴下方
AND DIFF < 0                # 当前DIF在0轴下方
```

**隔峰底钝化**（间隔一个峰值）：
```
CL1 < CL3                    # 价格创三次区间新低
AND DIFL1 < DIFL2            # DIF在前次区间最低
AND DIFL1 > DIFL3            # DIF高于更早区间最低（未新低）
AND REF(MACD, 1) < 0
AND DIFF < 0
```

**底部钝化**：
```
(直接底钝化 OR 隔峰底钝化) AND DIFF < 0
```

#### 底部结构（确认信号！）

```
条件：REF(底部钝化, 1) AND |REF(DIFF, 1)| >= |DIFF| * 1.01

含义：底部钝化形成后（上一根），DIF开始放大（绝对值增大1%以上）
      → 这是真正的买入确认信号！
```

**底结构形成**（首次出现）：
```
条件：REF(底部结构, 1) = 0 AND 底部结构
```

#### 底部钝化消失

```
条件：(REF(直接底钝化,1) AND DIFL1 <= DIFL2 AND DIFF < DEA)
   OR (REF(隔峰底钝化,1) AND DIFL1 <= DIFL3 AND DIFF < DEA)

含义：DIF继续创新低 → 底背离失效，可能加速下跌
```

#### 底部结构消失

```
条件：(CLOSE < CL2 OR CLOSE < CL1)
   AND REF(底部结构, M1+1) OR REF(底部结构, M1)
   AND NOT(REF(底钝化, 1))
   AND COUNT(底部结构, 24) >= 1

含义：价格跌破关键位（负区间最低点）→ 底部结构失效
```

### 3.4 顶部结构 · 量化条件

#### 顶部钝化（预警）

**直接顶钝化**：
```
CH1 > CH2                    # 价格新高（突破前负区间高点）
AND DIFH1 < DIFH2            # DIF未新高（DIF低于前负区间最高）
AND REF(MACD, 1) > 0         # 前一根MACD在0轴上方
AND DIFF > 0                # 当前DIF在0轴上方
```

**隔峰顶钝化**：
```
CH1 > CH3                    # 价格创三次区间新高
AND DIFH1 > DIFH2            # DIF在前次区间最高
AND DIFH1 < DIFH3            # DIF低于更早区间最高（未新高）
AND REF(MACD, 1) > 0
AND DIFF > 0
```

**顶部钝化**：
```
(直接顶钝化 OR 隔峰顶钝化) AND DIFF > 0
```

#### 顶部结构（确认信号！）

```
条件：REF(顶部钝化, 1) AND REF(DIFF, 1) >= DIFF * 1.01

含义：顶部钝化形成后（上一根），DIF开始缩小（值减小1%以上）
      → 这是真正的卖出确认信号！
```

#### 顶部钝化消失

```
条件：(REF(直接顶钝化,1) AND DIFH1 >= DIFH2 AND DIFF > DEA)
   OR (REF(隔峰顶钝化,1) AND DIFH1 >= DIFH3 AND DIFF > DEA)

含义：DIF继续创新高 → 顶背离失效，可能加速上涨
```

### 3.5 状态记忆变量

| 变量 | 定义 | 用途 |
|------|------|------|
| 底钝化 | 首次出现底部钝化 | 钝化开始计时 |
| 顶钝化 | 首次出现顶部钝化 | 钝化开始计时 |
| 底再次钝化 | 结构形成后再次出现钝化 | 结构强化 |
| 顶再次钝化 | 结构形成后再次出现钝化 | 结构强化 |

## 四、TD序列（第三优先级）

### 4.1 序列含义

| 序列 | 条件 | 含义 |
|------|------|------|
| TD买入序列 | 连续9根K线收盘价 < 4根前收盘价 | 下跌衰竭 |
| TD卖出序列 | 连续9根K线收盘价 > 4根前收盘价 | 上涨衰竭 |

### 4.2 序列生效条件

```
【关键规则】
钝化必须与序列共振，序列才能作为正式信号

- 底部钝化（空头趋势）+ TD序列低（6, 7, 8, 9） → 买入生效
- 顶部钝化（多头趋势）+ TD序列高（6, 7, 8, 9） → 卖出生效

【结构独立生效】
结构信号不需要序列确认，结构 > 钝化
```

## 六、决策流程

```
第一步：判断趋势（趋势为王）
    │
    ├─ 多头趋势 → 进入多头交易模式（只做多）
    ├─ 空头趋势 → 进入空头交易模式（只做空）
    └─ 震荡市   → 观望，不交易
            │
            ↓
第二步：判断结构（结构修边）
    │
    ├─ 有底部结构（多头趋势）→ 准备买入
    ├─ 有顶部结构（空头趋势）→ 准备卖出
    ├─ 有底部钝化（空头趋势）→ 准备买入（需序列确认）
    └─ 有顶部钝化（多头趋势）→ 准备卖出（需序列确认）
            │
            ↓
第三步：判断序列（序列为辅）
    │
    ├─ 钝化 + TD序列(6-9) → 信号生效
    ├─ 结构 → 无需序列，直接生效
    └─ 只有序列 → 无效，忽略
            │
            ↓
第四步：执行交易（根据强度决定仓位）
```

## 八、止损与止盈

### 8.1 止损

```
买入后：
  - ATR止损：入场价 - 3 * ATR(14)
  - 固定止损：入场价 - 5%

卖出后：
  - ATR止损：入场价 + 3 * ATR(14)
  - 固定止损：入场价 + 5%
```

### 8.2 止盈

```
卖出条件（多头持仓）：
  - RSI(14) > 70 → 部分止盈
  - 顶部结构形成 → 全部止盈
  - 峰值回撤 6% → 跟踪止盈

平仓条件（空头持仓）：
  - RSI(14) < 30 → 部分止盈
  - 底部结构形成 → 全部止盈
  - 峰值回升 6% → 跟踪止盈
```

## 十一、注意事项

1. **钝化 ≠ 信号**：钝化只是预警，结构才是正式信号
2. **消失 ≠ 错误**：消失表示原信号失效，不做错
3. **序列 alone 无效**：没有钝化的序列单独无效
4. **趋势优先**：震荡市中任何信号都忽略
5. **结构 > 钝化**：结构信号强度高于钝化
